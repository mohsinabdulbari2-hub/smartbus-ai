## SECTION 3 — Offline / Stale Data Handling

PROBLEM:
If fetch fails, some implementations clear the bus list → 
app looks empty and broken.

FIND your fetch/catch block. Apply this exact pattern:

  let lastKnownBuses = []; // module-level or ref, outside component

  async function fetchBuses() {
    try {
      const response = await apiFetch("/buses");
      const data     = await response.json();

      lastKnownBuses = data;          // ✅ store on success
      setBuses(data);
      setIsOffline(false);
      setLastFetchTime(Date.now());   // ✅ only on success

    } catch (error) {
      // ✅ Keep showing last known data
      if (lastKnownBuses.length > 0) {
        setBuses(lastKnownBuses);
      }
      setIsOffline(true);
      // ✅ Do NOT update lastFetchTime
      // ✅ Do NOT call setBuses([])
    }
  }

ADD offline banner — display when isOffline === true:

  {isOffline && (
    <Text style={styles.offlineBanner}>
      Offline • Showing last known data
    </Text>
  )}

STYLE for offline banner:
  - Amber or warning color text
  - Small, subtle — NOT a blocking modal
  - Appears below count label / timer
  - Disappears automatically when next fetch succeeds
