### R1-PATCH 2 — Tighten Text Hierarchy (4 Levels)

PROBLEM:
Multiple text elements have similar visual weight →
everything looks equally important → harder to scan.

APPLY this exact 4-level hierarchy across all bus cards:

    fontSize: 16
    fontWeight: "700"
    color: theme.text          // #E8ECF4
    letterSpacing: -0.3

  LEVEL 2 — ETA / "Arriving" (time-critical):
    fontSize: 14
    fontWeight: "600"
    color: theme.accent        // #3B82F6 normally

    letterSpacing: 0

  LEVEL 3 — Next Stop name (contextual):
    fontSize: 13
    fontWeight: "400"
    color: theme.text          // full color but lighter weight
    letterSpacing: 0

  LEVEL 4 — Distance / secondary labels (least important):
    fontSize: 11
    fontWeight: "400"
    color: theme.muted         // #6B7280
    letterSpacing: 0

RULES:
  - Apply ONLY to bus cards — do not touch header or filter
  - Do NOT change line spacing or card padding
  - Route number stays on its own line (already is)
  - ETA + Next Stop combined line: ETA part is Level 2 weight,
    "• Next: Stop Name" part drops to Level 3 weight
    → Achieve with nested <Text> elements:
        <Text style={level2}>
          {etaLabel}
          <Text style={level3}> • Next: {nextStop}</Text>
        </Text>
