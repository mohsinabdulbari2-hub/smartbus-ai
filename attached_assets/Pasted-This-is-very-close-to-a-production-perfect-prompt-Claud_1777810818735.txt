2. ⚠️ Timer memory leak risk
Claude used:
JavaScript
useEffect(() => {
  const interval = setInterval(...)
}, [lastFetchTime]);
👉 This is OK, but can re-create intervals repeatedly
✅ Safer version:
JavaScript
useEffect(() => {
  if (!lastFetchTime) return;

  const interval = setInterval(() => {
    setSecondsAgo(Math.floor((Date.now() - lastFetchTime) / 1000));
  }, 1000);

  return () => clearInterval(interval);
}, [lastFetchTime]);
👉 Prevents unnecessary intervals before first fetch
