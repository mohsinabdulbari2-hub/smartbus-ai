## PATCH 1 — ETA COUNTDOWN BETWEEN POLLS

---

GOAL:
ETA currently freezes between 8-second polls — feels static.
Make it count down every second like Uber — feels live.

---

STEP A — Add local ETA state per bus:

Each bus needs its own countdown. Use a ref-based 
countdown map to avoid re-render storms:

  // Outside component (module level):
  // Stores the "base" ETA at last fetch time, per bus ID
  const etaBaseRef = useRef<Record<string, {
    etaMinutes: number;
    fetchedAt:  number;
  }>>({});

STEP B — On every successful fetch, record base ETA:

  // Inside your existing successful fetch handler:
  // (where you currently call setBuses or similar)

  buses.forEach(bus => {
    if (bus.eta !== null && bus.eta !== undefined) {
      etaBaseRef.current[bus.id] = {
        etaMinutes: bus.eta,
        fetchedAt:  Date.now(),
      };
    }
  });

STEP C — Add a 1-second ticker:

  const [tick, setTick] = useState(0);

  useEffect(() => {
    const interval = setInterval(() => {
      setTick(t => t + 1); // force re-render every second
    }, 1000);
    return () => clearInterval(interval);
  }, []);

  // "tick" has no value itself — it just triggers re-render
  // so getLocalEta() is called fresh every second

STEP D — Compute live ETA per bus:

  function getLocalEta(busId: string): number | null {
    const base = etaBaseRef.current[busId];
    if (!base) return null;

    const elapsedMin =
      (Date.now() - base.fetchedAt) / 1000 / 60;

    const localEta = base.etaMinutes - elapsedMin;

    // Floor at 0 — never show negative
    return Math.max(localEta, 0);
  }

STEP E — Use in card render:

  // Replace existing bus.eta usage with:
  const localEta   = getLocalEta(bus.id);
  const isArriving =
    bus.distanceToNextStop < 30 ||
    (localEta !== null && localEta < 2);

  // ETA display:
  const safeEta = localEta !== null
    ? Math.max(Math.ceil(localEta), 1)
    : null;

  const etaNextStop = isArriving
    ? `Arriving • Next: ${nextStop}`
    : safeEta !== null
      ? `${safeEta} min • Next: ${nextStop}`
      : `— min • Next: ${nextStop}`;

STEP F — Clean up stale entries (memory safety):

  // Run after each successful fetch:
  const currentIds = new Set(buses.map(b => b.id));

  Object.keys(etaBaseRef.current).forEach(id => {
    if (!currentIds.has(id)) {
      delete etaBaseRef.current[id];
    }
  });

---

RULES:
  - ticker useEffect returns cleanup → no memory leak
  - etaBaseRef is a ref (not state) → no extra re-renders
  - Only the tick state triggers re-render (1/sec)
  - Never show negative ETA — floor at 0, display as "Arriving"
  - Never show "0 min" — Math.ceil + Math.max(1) handles this
  - If bus.eta is null/undefined → localEta returns null → show "—"
  - Clean up etaBaseRef entries for buses no longer in response
  - "Arriving" triggers when localEta < 2 OR distance < 30m
  - On next successful fetch → etaBaseRef resets for that bus
    → countdown restarts from new server ETA
  - Do NOT apply countdown to the sort logic —
    sort still uses raw server bus.eta (stable, no jitter)

## PATCH 2 — "CATCH IT" URGENCY SIGNAL

---

GOAL:
When a bus is arriving AND the user can still physically 
reach the stop in time — show an urgent, actionable signal.
Answers the question every transit user has:
"Can I still catch it?"

---

STEP A — Walking time calculation:

  // Uses existing distKm from Patch 3 of previous round
  // (haversine distance from user to bus)
  // Average walking speed: 5 km/h

  function getWalkTimeMin(distKm: number | null): number | null {
    if (distKm === null) return null;
    return (distKm / 5) * 60; // minutes to walk
  }

STEP B — Catchable condition:

  const localEta     = getLocalEta(bus.id);   // from Patch 1
  const walkTimeMin  = getWalkTimeMin(distKm); // existing distKm

  // Bus is catchable if:
  // 1. We know both values
  // 2. Walking time ≤ bus ETA + 1 min buffer
  // 3. Bus is not already gone (eta > 0)
  // 4. Bus is close enough to matter (eta ≤ 8 min)

  const isCatchable =
    localEta     !== null &&
    walkTimeMin  !== null &&
    localEta     > 0      &&
    localEta     <= 8     &&
    walkTimeMin  <= localEta + 1;

  // "Arriving" override — if bus is already arriving
  // and user is nearby → always show signal
  const isUrgent =
    isCatchable && (isArriving || localEta <= 3);

STEP C — Display signal in card:

  ADD below the ETA + Next Stop line:

  {isCatchable && (
    <View style={styles.catchItRow}>
      <Text style={styles.catchItText}>
        {isUrgent
          ? `⚡ Move now — ${Math.ceil(walkTimeMin)}min walk`
          : `✓ You can catch this — ${Math.ceil(walkTimeMin)}min walk`
        }
      </Text>
    </View>
  )}
