## PATCH 1 — FOLLOW BUS MODE (Core Feature)

GOAL:
When user taps a bus marker, the map camera smoothly 
follows that bus as it moves — like Uber tracking a ride.

STEP A — Add tracking state:

  const [trackedBusId, setTrackedBusId]   = useState(null);
  const [hasInitialZoomed, setHasInitialZoomed] = useState(false);
  const mapRef = useRef(null); // attach to map component if not done

STEP B — On marker tap, start tracking:

  onPress={() => {
    setTrackedBusId(bus.id);
    setHasInitialZoomed(false); // reset so zoom fires once
    setSelectedBus(bus);        // existing bottom sheet logic
  }}

STEP C — Camera follow effect:

  useEffect(() => {
    if (!trackedBusId) return;

    const trackedBus = buses.find(b => b.id === trackedBusId);
    if (!trackedBus) return;

    // Only zoom on first follow — then only pan
    if (!hasInitialZoomed) {
      mapRef.current?.animateCamera({
        center: {
          latitude:  trackedBus.lat,
          longitude: trackedBus.lng,
        },
        zoom: 15,
      }, { duration: 800 });
      setHasInitialZoomed(true);
    } else {
      // Subsequent updates: move center only, no zoom change
      mapRef.current?.animateCamera({
        center: {
          latitude:  trackedBus.lat,
          longitude: trackedBus.lng,
        },
      }, { duration: 600 });
    }

  }, [buses, trackedBusId]);

RULES:
  - Duration 600–800ms — smooth, not instant
  - Never call animateCamera if trackedBusId is null
  - Never change zoom after the first follow pan
  - If trackedBus not found in buses array → silently return
    (bus may have left viewport — do not crash)
  - mapRef must be attached to the map component:
      <MapView ref={mapRef} ... />

## PATCH 4 — BUS HEADING DIRECTION

GOAL:
Bus marker rotates to show direction of travel —
feels like real navigation.

STEP A — Check if API already returns heading/bearing field.
  If yes: use bus.heading directly.
  If no: compute approximate bearing from movement.

COMPUTE BEARING (if not in API):

  function getBearing(prevLat, prevLng, nextLat, nextLng) {
    const dLng = (nextLng - prevLng) * (Math.PI / 180);
    const lat1  = prevLat * (Math.PI / 180);
    const lat2  = nextLat * (Math.PI / 180);

    const y = Math.sin(dLng) * Math.cos(lat2);
    const x =
      Math.cos(lat1) * Math.sin(lat2) -
      Math.sin(lat1) * Math.cos(lat2) * Math.cos(dLng);

    const bearing = Math.atan2(y, x) * (180 / Math.PI);
    return (bearing + 360) % 360; // normalize to 0–360
  }

STORE previous position per bus to compute bearing:

  const prevPositions = useRef({});

  // In bus update loop:
  const prev = prevPositions.current[bus.id];
  const bearing = prev
    ? getBearing(prev.lat, prev.lng, bus.lat, bus.lng)
    : bus.heading ?? 0;

  prevPositions.current[bus.id] = {
    lat: bus.lat,
    lng: bus.lng
  };

APPLY rotation to marker:

  IF React Native Maps:
    <Marker
      coordinate={{ latitude: bus.lat, longitude: bus.lng }}
      rotation={bearing}
      anchor={{ x: 0.5, y: 0.5 }}
    />

  IF Leaflet:
    marker.setRotationAngle(bearing); 
    // requires leaflet-rotatedmarker if available
    // if not available → skip rotation, do not add dependency

ANTI-JITTER RULE — Smooth bearing changes:

  // Only update bearing if change > 5 degrees
  // Prevents jitter from GPS noise

  const prevBearing = busMarkerState[bus.id]?.bearing ?? 0;
  const bearingDelta = Math.abs(bearing - prevBearing);

  const smoothBearing =
    bearingDelta > 5 ? bearing : prevBearing;

RULES:
  - If heading not in API and prev position not yet stored
    → default to 0 (pointing north) for first render
  - Do NOT add leaflet-rotatedmarker or any plugin
  - If rotation causes marker issues → skip this patch
  - Anti-jitter threshold: only rotate if delta > 5 degrees
